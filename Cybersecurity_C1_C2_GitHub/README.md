# Cybersecurity: C1–C2 Python Assignment

Учебный проект на Python по анализу событий информационной безопасности и объектно-ориентированному программированию.

## Содержание работы

**C1 — анализ данных безопасности:**

- C1.1 — разбор SSH-журналов;
- C1.2 — обнаружение попыток brute force;
- C1.3 — извлечение индикаторов компрометации (IOC);
- C1.4 — проверка надёжности паролей;
- C1.5 — контроль целостности файлов;
- C1.6 — проверка срока действия TLS-сертификатов.

**C2 — ООП и проектирование системы:**

- C2.1 — модель события безопасности;
- C2.2 — парсеры на основе абстрактного класса;
- C2.3 — система правил обнаружения;
- C2.4 — класс для маскирования секретных значений;
- C2.5 — принцип подстановки Лисков (LSP);
- C2.6 — способы отправки предупреждений с помощью `Protocol`.

## Запуск в Google Colab

1. Откройте [`Cybersecurity_C1_C2_Clean_Colab.ipynb`](Cybersecurity_C1_C2_Clean_Colab.ipynb) в Google Colab (через **Файл → Открыть блокнот → GitHub**).
2. Выберите **Среда выполнения → Выполнить все**.
3. Ноутбук сам создаст папки `seclab`, `examples`, `tests`, примеры данных и запустит тесты.

**Важно:** ячейки `%%writefile` должны выполниться до ячеек, в которых импортируются соответствующие модули. Если Colab перезапустил среду выполнения, запустите ячейки сначала.

Для дополнительной проверки `mypy` предварительно выполните в отдельной ячейке:

```python
%pip install -q mypy
```

## Структура проекта


## Тестирование вне Colab (необязательно)

```bash
python -m pip install -r requirements.txt
python -m pytest -q tests
python -m examples.demo
```

В примерах используются синтетические данные, а не реальные учётные данные или логи организации.
